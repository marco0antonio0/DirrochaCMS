# Código de Conduta

O DirrochaCMS é um projeto open source. Queremos um ambiente técnico, respeitoso e produtivo para pessoas mantenedoras, contribuidoras e usuárias.

## Comportamentos esperados

- Tratar outras pessoas com respeito.
- Discordar de ideias sem atacar pessoas.
- Ser objetivo ao reportar bugs, propor mudanças ou revisar código.
- Aceitar feedback técnico com abertura.
- Dar contexto suficiente para que outras pessoas consigam ajudar.
- Respeitar limites de tempo e disponibilidade de mantenedores.

## Comportamentos não aceitos

- Assédio, intimidação, ofensas ou ataques pessoais.
- Linguagem discriminatória ou sexualizada.
- Exposição de dados privados sem consentimento.
- Comentários que desviem discussões técnicas para ataques ou provocações.
- Spam, autopromoção abusiva ou uso do projeto para fins maliciosos.

## Aplicação

Mantenedores podem remover comentários, fechar issues, bloquear interações ou recusar contribuições que violem este código de conduta.

Medidas serão proporcionais ao impacto da conduta e ao histórico da interação.

## Como reportar

Se você presenciar ou sofrer uma violação, reporte aos mantenedores pelo GitHub do projeto:

https://github.com/marco0antonio0/DirrochaCMS

Inclua contexto suficiente para análise, como links, prints, datas e descrição objetiva do ocorrido.

## Escopo

Este código vale para issues, pull requests, discussões, documentação, canais relacionados ao projeto e interações públicas em nome do DirrochaCMS.

# Code of Conduct

<p>
  <strong>English</strong> · <a href="./CODE_OF_CONDUCT.pt-BR.md">Português (Brasil)</a>
</p>

DirrochaCMS is an open source project. We want a technical, respectful and productive
environment for maintainers, contributors and users.

## Expected behavior

- Treat other people with respect.
- Disagree with ideas without attacking people.
- Be objective when reporting bugs, proposing changes or reviewing code.
- Accept technical feedback with an open mind.
- Give enough context for other people to be able to help.
- Respect the time and availability limits of maintainers.

## Unacceptable behavior

- Harassment, intimidation, insults or personal attacks.
- Discriminatory or sexualized language.
- Disclosure of private data without consent.
- Comments that divert technical discussions into attacks or provocation.
- Spam, abusive self-promotion, or use of the project for malicious purposes.

## Enforcement

Maintainers may remove comments, close issues, block interactions or reject contributions that
violate this code of conduct.

Measures will be proportional to the impact of the conduct and to the history of the
interaction.

## How to report

If you witness or experience a violation, report it to the maintainers through the project's
GitHub:

https://github.com/marco0antonio0/DirrochaCMS

Include enough context for review, such as links, screenshots, dates and an objective
description of what happened.

## Scope

This code applies to issues, pull requests, discussions, documentation, project-related
channels, and public interactions on behalf of DirrochaCMS.

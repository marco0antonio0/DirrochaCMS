# OsteoPlay Vet Screenshots

This folder contains archived screenshots of the OsteoPlay Vet case study. The
images document the deployed application flow.

## Files

| File | Content |
| --- | --- |
| [`01-home-hero.png`](./01-home-hero.png) | OsteoPlay Vet landing section with the two main learning modes, `Vet-Ossos` and `Vet-Perguntas`. |
| [`02-home-resources.png`](./02-home-resources.png) | Home/resource section with cards for `Sobre o OsteoPlayVet`, atlas access, and the external Veterinary Anatomy Viewer resource. |
| [`03-about-project.png`](./03-about-project.png) | `Sobre o Projeto` screen showing academic objective, methodology, and project scope text. |
| [`04-difficulty-selection.png`](./04-difficulty-selection.png) | Difficulty selection screen for `Vet-Ossos`, with `Iniciante` and `Desafiante` levels. |
| [`05-vet-ossos-gameplay.png`](./05-vet-ossos-gameplay.png) | Gameplay screen consuming CMS-backed bone-identification content, including image, hint, progress, and answer input. |

## Notes

- The screenshots demonstrate that the frontend is a real educational
  application, not only a static mockup.
- The screens show project information, learning modes, difficulty selection,
  and gameplay content that matches the Firestore endpoint schemas documented
  in `examples/osteoplay-vet`.
- The PNG files are stored in this directory so that the material remains
  available even if the live Netlify site goes offline.

# Capturas do OsteoPlay Vet

Esta pasta contém capturas arquivadas do estudo de caso OsteoPlay Vet. As telas
documentam o fluxo da aplicação implantada.

## Arquivos

| Arquivo | Conteúdo |
| --- | --- |
| [`01-home-hero.png`](./01-home-hero.png) | Seção inicial do OsteoPlay Vet com os dois modos principais de aprendizagem, `Vet-Ossos` e `Vet-Perguntas`. |
| [`02-home-resources.png`](./02-home-resources.png) | Seção de recursos com cards para `Sobre o OsteoPlayVet`, acesso ao atlas e recurso externo Veterinary Anatomy Viewer. |
| [`03-about-project.png`](./03-about-project.png) | Tela `Sobre o Projeto`, exibindo objetivo acadêmico, metodologia e escopo do projeto. |
| [`04-difficulty-selection.png`](./04-difficulty-selection.png) | Tela de seleção de dificuldade do `Vet-Ossos`, com níveis `Iniciante` e `Desafiante`. |
| [`05-vet-ossos-gameplay.png`](./05-vet-ossos-gameplay.png) | Tela de gameplay consumindo conteúdo de identificação de ossos vindo do CMS, com imagem, dica, progresso e entrada da resposta. |

## Notas

- As capturas demonstram que o frontend é uma aplicação educacional real, não
  apenas um mockup estático.
- As telas mostram informações do projeto, modos de aprendizagem, seleção de
  dificuldade e conteúdo de jogo compatível com os schemas Firestore
  documentados em `examples/osteoplay-vet`.
- Os arquivos PNG estão armazenados nesta pasta para que o material continue
  disponível mesmo se o site da Netlify sair do ar.

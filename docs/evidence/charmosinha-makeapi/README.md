# Charmosinha / MakeAPI Screenshots

This folder contains archived screenshots of the Charmosinha/MakeAPI case
study. The images document the deployed learning-oriented storefront.

## Files

| File | Content |
| --- | --- |
| [`01-home-hero.png`](./01-home-hero.png) | Charmosinha storefront landing page with promotional banner, navigation, free-shipping notice, benefit cards, and WhatsApp action. |
| [`02-product-grid.png`](./02-product-grid.png) | Product catalog section populated from the MakeAPI/DirrochaCMS backend, showing product cards, fictional product images/names, categories, prices, size selectors, and add-to-cart buttons. |

## Notes

- The storefront, platform name, product names, images, and catalog content are
  fictional and were used only for learning/educational purposes in a software
  engineering discipline at UNAMA Parque Shopping.
- The screenshots demonstrate a real frontend consuming backend-managed product
  data, not a production commerce system.
- The PNG files are stored in this directory so that the material remains
  available even if the live Netlify site goes offline.

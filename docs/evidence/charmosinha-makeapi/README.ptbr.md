# Capturas da Charmosinha / MakeAPI

Esta pasta contém capturas arquivadas do estudo de caso Charmosinha/MakeAPI. As
telas documentam a loja didática implantada.

## Arquivos

| Arquivo | Conteúdo |
| --- | --- |
| [`01-home-hero.png`](./01-home-hero.png) | Tela inicial da loja Charmosinha com banner promocional, navegação, aviso de frete grátis, cards de benefícios e ação de WhatsApp. |
| [`02-product-grid.png`](./02-product-grid.png) | Seção de catálogo preenchida a partir do backend MakeAPI/DirrochaCMS, mostrando cards de produtos, imagens/nomes fictícios, categorias, preços, seleção de tamanhos e botões de adicionar ao carrinho. |

## Notas

- A loja, o nome da plataforma, nomes de produtos, imagens e conteúdos do
  catálogo são fictícios e foram usados apenas para fins de aprendizado em uma
  disciplina de Engenharia de Software da UNAMA Parque Shopping.
- As capturas demonstram um frontend real consumindo dados de produtos
  gerenciados pelo backend, não um sistema de comércio em produção.
- Os arquivos PNG estão armazenados nesta pasta para que o material continue
  disponível mesmo se o site da Netlify sair do ar.
